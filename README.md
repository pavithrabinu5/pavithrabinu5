## Selected Projects

### IgnisAI — Multi-Agent AI Emergency Response System
*Finalist, HackXelerator 2026*

A five-agent orchestrated system (LangGraph) for GPS-denied environments, integrating physics-informed hazard modelling, YOLOv8 computer-vision detection, adaptive pathfinding, and Claude API vision-based reasoning. Inter-agent state-sharing enables full system re-planning within thirty seconds of a changed condition.

### Milo — Real-Time LLM Multi-Agent Intelligence System
*94% Extraction Accuracy · ~400ms Latency · 99%+ Uptime*

A Dockerized real-time pipeline (FastAPI, Next.js, PostgreSQL, WebSockets) combining Whisper ASR, LLaMA, and the Claude API with prompt engineering and RAG-style context management. Supports over one thousand concurrent events per session.

### PrimeWave — Full-Stack E-Commerce Platform
*Production-Deployed, Live Users*

A full customer purchase lifecycle — catalog, cart, checkout, and authentication — built with Django, MySQL, and REST APIs, deployed via a continuous integration and delivery pipeline.

### Prognos — Clinical Multi-Disease Prediction System
*99.1% Accuracy · AUC 0.999*

A soft-voting ensemble of four classifiers with SMOTE class-imbalance correction across three clinical domains, served through a Flask REST API for real-time inference.

Benchmarked EfficientNet, ResNet50, and Vision Transformer architectures with Grad-CAM explainability, deployed via HuggingFace Spaces and Gradio.

### Strata Forecast — Large-Scale ETL and Forecasting Platform

An ETL pipeline processing over three million records across fifty-four locations, with automated stakeholder-facing dashboards.

### IntelliTicket — NLP Classification and Analytics Dashboard
*100% Accuracy · F1: 1.0*

## Research and Publication

**High-Performance Brain-Computer Interfaces: A Critical Evaluation of AI-Driven Neural Decoding Technologies**
*Artificial Intelligence Module, University of West London (RAK Campus), 2025*

A structured critical evaluation of five landmark BCI studies published in *Nature* and *The Lancet* between 2006 and 2023, tracing the evolution of neural decoding from linear models to LLM-integrated systems. Identified a four- to five-fold increase in communication bandwidth between 2019 and 2023, and documented open gaps in long-term signal stability, cross-subject generalisation, bidirectional feedback, and evaluation standardisation.
